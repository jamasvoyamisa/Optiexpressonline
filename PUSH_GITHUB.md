# Subir a GitHub

Después de crear el repositorio en github.com, ejecuta (reemplaza TU_USUARIO con tu usuario de GitHub):

```bash
cd /Users/marcodiaz/Desktop/Proyectos/Optiexpressonline

git remote add origin https://github.com/TU_USUARIO/Optiexpressonline.git
git push -u origin main
```

Si el repo tiene otro nombre, usa esa URL en lugar de Optiexpressonline.
