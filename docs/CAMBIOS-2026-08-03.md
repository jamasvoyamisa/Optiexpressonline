## 1. Justificar incidencias — encargados del área

**Problema:** `jsandoval` (Supervisor Laboratorio, encargado de Tallado/AR/Biselado/etc.) podía **ver** incidencias de su área en Mi Área, pero al pulsar **Guardar** el backend respondía **403** y el frontend no mostraba el error (parecía que el botón no hacía nada).

**Causa:**
- Listar (`GET /asistencia/incidencias/mi-area`) usa `get_departamento_ids_que_administro` (incluye **encargados**).
- Guardar (`PATCH /asistencia/incidencias/{id}`) solo aceptaba `get_ids_aprobadores_area` (jefes + gerente/supervisor del **mismo** `departamento_id`) o Gerente General. Un encargado de Tallado con puesto en Laboratorio no entraba en esa lista.
- `saveJustificacion` no tenía `.catch()` → 403 silencioso.

**Solución:**
- El PATCH permite justificar también si el departamento del empleado está en `departamento_ids_que_administro` del usuario (misma regla que ver el listado).
- Se mantiene la regla: un supervisor (solo) no justifica incidencias de otros supervisores/gerentes.
- El modal muestra `alert` con el mensaje del API si falla.

**Archivos:**
- `backend/app/modules/asistencia/routes.py` (`update_incidencia`)
- `frontend/src/modules/mi-area/MiAreaPage.tsx` (`saveJustificacion`)
