## 2. MySQL local — arranque

En esta PC MySQL Server **8.4.9** ya estaba instalado (`C:\Program Files\MySQL\MySQL Server 8.4`), con datos en `C:\ProgramData\MySQL\MySQL Server 8.4\Data`, pero **no había servicio Windows** registrado y el puerto **3306** estaba cerrado.

- Se arrancó `mysqld` a mano (consola / proceso en segundo plano), no como servicio.
- Credenciales locales usadas (alineadas a `backend/.env`):
  - Usuario: `optiexpress_user`
  - BD: `optiexpress_online`
  - Puerto: `3306`

**Importante:** si se reinicia la PC o se mata el proceso `mysqld`, hay que volver a levantarlo. Queda pendiente dejarlo como servicio Windows (requiere elevación / UAC).
